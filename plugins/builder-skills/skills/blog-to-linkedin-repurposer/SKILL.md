# Blog-to-LinkedIn Repurposer

## What it does

Takes a single blog post and spins out a week of LinkedIn posts, each with a different angle and hook — multiplying a solo marketer's output without rewriting from scratch.

## When to use

- "Repurpose this blog for LinkedIn", "make a week of posts from this article".

## Inputs

The article (pasted text or URL). Optional: voice/tone, target audience, posting cadence.

## Workflow

1. **Mine the source** for distinct ideas: the core thesis, supporting points, a stat or example, a contrarian take, a practical how-to.
2. **Assign angles** so the posts don't repeat — e.g. hot take, story, listicle, stat-led, question-to-the-audience.
3. **Write 5 posts.** Each: a strong first-line hook, native LinkedIn formatting (short lines, white space), one idea, a soft CTA.
4. **Add hashtags** (3-5, mixed reach) and a suggested posting day.
5. **Output** the set, paste-ready.

## Output

```
### Post 1 — [angle] — suggested: [day]
[hook line]

[body in short lines]

[soft CTA]
#tag #tag #tag

### Post 2 — [angle] — …
```

## Notes

- Match the user's voice if samples are given; otherwise default to clear, practitioner-to-practitioner.
- Keep each post to one idea — five focused posts beat one that does everything.
